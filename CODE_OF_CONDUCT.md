# Code of Conduct

This project follows a simple rule: be kind and be constructive.

## Expected behaviour

- Be respectful and welcoming to everyone, whatever their background or experience.
- Give feedback on the work, not the person, and accept feedback the same way.
- Assume good intent, and ask when something is unclear.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Sexualised language or imagery, and unwelcome attention.
- Publishing other people's private information.
- Spam or other disruptive behaviour in issues and pull requests.

## Enforcement

The maintainer may edit, hide or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, open an issue or contact the maintainer through their GitHub profile at https://github.com/SOHAIL-IQB.

This code of conduct applies in the repository's issues, pull requests and discussions.
